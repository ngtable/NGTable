# Contributing

Thank you for wanting to help.

**Issues are welcome:** bug reports, questions, ideas and performance
findings. For a bug, say which NGTable version (`NGTableView.version`) and
macOS version you have, and how to make it happen; a small project or a
failing test helps most.

**Pull requests aren't accepted for now.** NGTable is licensed under two
licenses (see [LICENSING.md](LICENSING.md)), so all its code has to come from
its author. If you've found a fix, describe it in an issue: it will be
written into NGTable, and credited to you if you like.
